# AMZ 数据台 · 交互原型（v0.9）

亚马逊卖家内部数据管理后台的**需求确认用原型**。纯静态，无后端、无构建步骤。
所有数据为虚构演示数据，用于对齐页面结构与字段口径，不代表真实业务数值。

## v0.9 变更（2026-10-26，对应客户第 5 轮反馈）

1. 顶部期间筛选改为：今日 / 昨日 / 近 3 天 / 近 7 天 / 近 14 天 / 本月 / 上月 / 自定义；首页、销售、广告、资金的汇总与明细同步按所选期间出数。
2. 首页新增「广告花费」KPI 与趋势线；**曲线悬停按「产品编号 + 规格」列出对应数量**；KPI 与库存水位支持悬停看口径明细。
3. 销售页顶部卡片改为 销售额 / 销量 / 广告花费 / 毛利（广告费与毛利从广告表实时取数）；SKU 卡片改为「销售额 + 销量 + 广告花费」三系列柱状图；多维对比可按店铺 / 站点切换。
4. 销售明细增加 日期 / 站点 / ASIN / 币种 / 本币销售额，支持分页（每页 10 条）与横向滚动。
5. 产品开发：进度改为四段小长条（选品评估 → 打样 → 量产 → 上市，已完成变蓝），去掉完成度与「供应商与打样」「开发成本归集」卡片。
6. 采购管理：新增店铺 / 站点列，修复表头错位，进度增加「回退」防误点；供应商可在基础档案维护。
7. 货物流动：海外仓全部替换为 FBA 库存，改为「库存水位 + 国内在途 + FBA 在途 + 建议补货 + 链路状态」数据栏，支持列设置与分页。
8. 新增「广告运营」页：SP 商品推广 / SB 品牌推广 / SD 展示推广，按 店铺 × 站点 × SKU 归集，支持勾选批量操作，数据回写销售毛利与首页。
9. 基础档案：去掉「仓库/货代」「费用科目」，店铺去掉店铺代码列（店铺 = 公司名称）；新增站点维护、SKU 利润表（含退款、每日更新的成本项）、供应商。
10. 销售录入改为本币录入，折算人民币后计入汇总。

## 页面

| 路由 | 页面 | 要点 |
|---|---|---|
| `#/overview` | 首页总览 | 销售额/毛利/广告花费/退款/应付 + 环比、三维趋势、待办、资金、在途、FBA 快照 |
| `#/todo` | 待办中心 | 按级别筛选、建议动作、处理/忽略 |
| `#/sales` | 销售数据 | 销售额/销量/广告花费/毛利、SKU 三系列柱状图、店铺/站点对比、按日明细 |
| `#/ads` | 广告运营 | SP/SB/SD、曝光/点击/CTR/CPC/ACOS/ROAS、活动列表、按日录入 |
| `#/product` | 产品开发 | 项目台账、四段流程进度 |
| `#/purchase` | 采购管理 | 采购单推进（9 阶段，可推进/回退）+ 批次追踪 + 供应商维护 |
| `#/goods` | 货物流动 | FBA 库存与补货建议、库存水位、在途与到仓、库龄分布 |
| `#/cash` | 资金流动 | 账户余额、收支趋势、流水明细、费用分摊、应付账款 |
| `#/master` | 基础档案 | 店铺（公司）、站点、SKU 利润表、供应商 |
| `#/import` | 数据导入 | 模板下载、上传区、导入记录、失败行原因 |
| `#/account` | 账号与日志 | 账号增停（无权限区分）、操作日志、部署信息 |

## 本地预览

```bash
cd prototype
python3 -m http.server 8787
# 打开 http://localhost:8787/
```

## 打包单文件（发客户 / 传飞书）

```bash
./build.sh    # 生成 AMZ-数据台-原型.html，CSS/JS 全部内联，可离线双击打开
```

## 发布到 GitHub Pages

```bash
./deploy.sh <repo-name>            # 例：./deploy.sh amz-data-console-demo
```

需要：仓库已在 GitHub 建好（public），本机有推送权限。
Pages 开启：仓库 Settings → Pages → Source 选 `main` / `root`。

## 口径与边界

- 只做桌面（1024–1920）；手机仅用于评审，不是交付范围
- 不做权限区分，所有启用账号权限相同
- 不接任何外部平台，数据靠手工录入或 Excel 导入
- 数据身份 = 店铺（公司）× 站点（销售国）× SKU
- 库存只做 FBA 仓模式，不做海外仓；补货建议 = 45 天销量 − FBA 可售 − 在途
- 毛利：销售额 − 退款 − 采购成本 − 头程 − 仓储 − 平台佣金 − 平台配送费 − 广告，汇率按人工维护的静态表
- 期间筛选只影响汇总与明细展示，不改已入库数据；采购/库存为当前时点快照

## 技术

- 原生 HTML/CSS/JS，无框架
- Chart.js 4（本地打包，无外网依赖）
- hash 路由，刷新不 404
- `build.sh` 内联打包单文件

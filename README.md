# AMZ 数据台 · 交互原型

亚马逊卖家内部数据管理后台的**需求确认用原型**。纯静态，无后端、无构建步骤。
所有数据为虚构演示数据，用于对齐页面结构与字段口径，不代表真实业务数值。

## 页面

| 路由 | 页面 | 要点 |
|---|---|---|
| `#/overview` | 首页总览 | KPI + 环比、销售/毛利趋势、资金收支、货物在途、库存快照、待办与异常 |
| `#/todo` | 待办中心 | 按级别筛选、建议动作、处理/忽略 |
| `#/purchase` | 采购流程 | 采购申请→审批→下单→付款→发货→头程→清关→到仓→入库，可推进与看时间线 |
| `#/cash` | 资金流动 | 账户余额、收支趋势、流水明细、费用分摊、应付账款 |
| `#/goods` | 货物流动 | 在途航线、库龄分布、海外仓库存台账 |
| `#/sales` | 销售数据 | 销售额/销量/退款率/毛利、SKU 毛利、店铺×月份对比、销售明细 |
| `#/product` | 产品开发 | 项目台账、供应商打样、开发成本归集 |
| `#/import` | 数据导入 | 模板下载、上传区、导入记录、失败行原因 |
| `#/account` | 账号与日志 | 账号增停（无权限区分）、操作日志、部署信息 |

## 本地预览

```bash
cd prototype
python3 -m http.server 8787
# 打开 http://localhost:8787/
```

## 发布到 GitHub Pages

```bash
./deploy.sh <repo-name>            # 例：./deploy.sh amz-data-console-demo
```

需要：仓库已在 GitHub 建好（public，空仓库），本机 SSH key 已加入 GitHub 账号。
Pages 开启：仓库 Settings → Pages → Source 选 `main` / `root`。

## 口径与边界（对应需求清单 v4）

- 不做手机/平板适配，仅桌面布局自适应（1024–1920）
- 不做权限区分，所有启用账号权限相同
- 不接任何外部平台，数据靠手工录入或 Excel 导入
- 库存：移动加权平均计价，在途单列、不计入可用库存
- 毛利：销售额 − 退款 − 采购成本 − 头程 − 仓储 − 平台佣金 − 广告，汇率人工维护
- 不导入历史业务数据

## 技术

- 原生 HTML/CSS/JS，无框架
- 原型可手机查看（导航改为顶部胶囊、表格内部横向滚动），但**交付范围仍只做桌面**，手机仅用于评审
- Chart.js 4（本地打包，无外网依赖）
- hash 路由，刷新不 404
